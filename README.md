## Робота з Git

1. `main` містить початковий коміт із матеріалами, а надалі — зміни, прийняті через Pull Request.
2. `develop` створюється від початкового коміту `main`; у ній виконується домашня робота.
3. Обидві гілки публікуються на GitHub через remote `origin`.
4. Завершені зміни передаються через Pull Request **`develop` → `main`**.
5. Після початкової публікації прямі робочі коміти в `main` не додаються.

Репозиторій: [energy6x6/Go-with-GenAI-lessons-12](https://github.com/energy6x6/Go-with-GenAI-lessons-12).

## Подальша робота в develop

- Перевірити середовище та відтворити запуск наданого демо локально через Floci і SAM.
- Підтвердити HTTP-відповіді та окремо автоматичний S3-тригер.
- Згенерувати Terraform, розібрати кожен рядок і перевірити конфігурацію та план.
- Реалізувати власну функцію з HTTP-тригером і позитивними та негативними тестами.
- Підготувати відтворювані команди, фактичні результати та докази виконання.

Локальні секрети, Terraform state, дані емулятора та артефакти збірки
не додаються до Git.
