# Демонстрація Lesson 12

Команди виконуються з кореня проєкту. Спочатку `source scripts/env.sh`.
Логи й відповіді записуйте в зовнішній `LESSON12_EVIDENCE_DIR`, знімки —
в особисту папку доказів. Фінальний звіт створюється після отримання скриншотів.

| Крок | Команда / дія | Що має бути видно |
|---|---|---|
| 1 | `git branch --show-current`; `make test` | Робоча гілка develop, усі три пакети проходять тести |
| 2 | `make build`; `make sam-build`; `make sam-invoke` | Linux bootstrap; SAM повертає 200 та 400 для обох HTTP-функцій |
| 3 | Відкрити `docs/TERRAFORM_REVIEW.md` поряд із `.tf` файлами | Особистий розбір рядків, ролей і тригерів |
| 4 | `make plan-tf` | Зрозумілий план; після завершеного apply немає неочікуваних змін |
| 5 | `make smoke` | Обидва HTTP-маршрути, автоматичний S3-тригер, PNG 133 × 200, повторна подія |
| 6 | HTTP curl із README для reader valid та invalid | 200 з нормалізованим профілем та 400 з поясненням |
| 7 | `make bench` | Окремі cold/warm пари та застереження про локальне вимірювання |
| 8 | GitHub PR develop → main | Файли застосунків, конфігурації та стан CI |

Оригінальний архівний README містить старий smoke з ручним fallback і широкою
спільною роллю. Для цієї роботи використовуйте актуальні сценарії з кореня.
Не називайте ручний Lambda invoke доказом роботи S3 notification.
Не перезапускайте контейнер Floci чи VM під час запису cold/warm серії.
Не запускайте очищення до збереження доказів.
